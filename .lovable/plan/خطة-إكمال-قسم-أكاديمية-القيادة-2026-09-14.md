# خطة إكمال قسم أكاديمية القيادة

## الهدف
إكمال الأكاديمية كتجربة تعليمية مترابطة تعمل فعليًا للطالب والمدرب والمسؤول، مع إضافة صورة غلاف قابلة للرفع والتعديل لكل دورة. تبقى تسمية القسم الرئيسية **أكاديمية القيادة** بالعربية، وتبقى بقية واجهات النظام ورسائله بالإنجليزية وفق هوية التطبيق الحالية.

## 1. استكمال بنية البيانات والحماية
- إضافة ربط آمن بين الدورة وحساب المدرب، ودور مستقل للمدرب، مع صلاحيات تمنحه إدارة دوراته المعيّنة فقط.
- إضافة متطلبات الإكمال القابلة للضبط، وترتيب/قفل الدروس، والواجبات أو المشاريع، وتسليماتها وتقييماتها.
- إضافة أسئلة ومناقشات الدورة وردود المدرب وحالات الحل والإشراف.
- توسيع حساب التقدم ليشمل الدروس المطلوبة والاختبارات المطلوبة والواجبات المطلوبة، مع نسب تفصيلية لكل وحدة.
- جعل إكمال الدورة وإصدار الشهادة عملية ذرّية وآمنة تمنع التكرار والتعارض، ولا تتم إلا بعد استيفاء جميع المتطلبات.
- تطبيق صلاحيات أقل امتيازًا وسياسات وصول افتراضية مغلقة، والتحقق من المدخلات، وسجل تدقيق لتغييرات الإدارة والتقييمات.

## 2. صور الدورات والملفات التعليمية
- إنشاء مساحة ملفات خاصة بوسائط الأكاديمية، بصلاحيات قراءة آمنة للمواد المسموحة ورفع/تعديل للمدرب المسؤول أو مدير الأكاديمية فقط.
- إضافة رفع صورة غلاف لكل دورة من صفحة الإنشاء والتعديل، مع معاينة، استبدال، حذف، والتحقق من النوع والحجم.
- عرض صورة الدورة في بطاقات الأكاديمية وصفحة التفاصيل و"My courses" وصفحة الإتمام، مع بديل بصري ثابت عند عدم وجود صورة.
- دعم رفع ملفات الدروس ومصادرها وملفات الواجبات والفيديوهات ضمن حدود آمنة، واستخدام روابط مؤقتة للملفات الخاصة.

## 3. تجربة الطالب
- تحسين صفحة قائمة الدورات لتعرض الصورة، الاسم، المدرب، التقييم، المدة، المستوى، ونسبة التقدم الفعلية، مع البحث والتصنيفات والفلاتر الحالية.
- إكمال صفحة تفاصيل الدورة بالصورة، الوصف، المخرجات، المتطلبات، المدرب، التقييم، المدة، عدد الدروس، وحالة التسجيل المناسبة.
- إنشاء صفحة تعلم متجاوبة تشمل:
  - مشغل الفيديو أو محتوى الدرس.
  - الوحدات والدروس مع حالات مكتمل/حالي/مقفل.
  - الملفات والمصادر.
  - ملاحظات شخصية محفوظة تلقائيًا بأمان.
  - أسئلة ومناقشات الدورة.
  - الاختبارات والواجبات والمشاريع.
  - حفظ آخر درس وتحديث التقدم فور كل إنجاز.
- إنشاء واجهة الاختبار، حفظ المحاولة والنتيجة، توضيح النجاح أو عدم الاجتياز، والسماح بإعادة المحاولة وفق إعداد الاختبار.
- إنشاء واجهة تسليم الواجبات ومتابعة حالة التقييم وملاحظات المدرب.
- إنشاء صفحة "My courses" بتبويبات لم يبدأ، قيد التعلم، ومكتمل، مع شريط تقدم وأزرار المتابعة والشهادة.

## 4. الإتمام والشهادات
- إنشاء صفحة إتمام تعرض التهنئة، اسم الطالب والدورة والمدرب، تاريخ الإكمال، النتيجة النهائية، الساعات، وزر الشهادة.
- إنشاء شهادة رقمية متجاوبة وقابلة للطباعة/الحفظ، تتضمن البيانات المطلوبة ورقمًا فريدًا ورمز QR ورابط تحقق.
- إنشاء صفحة تحقق عامة تقبل الرقم أو رابط QR، وتعرض بوضوح شهادة صالحة أو غير موجودة دون كشف بيانات غير لازمة.
- ربط الشهادة بحساب الطالب وإظهارها في "My courses" وصفحة الحساب.

## 5. لوحة المدرب
- إنشاء لوحة مخصصة تعرض دورات المدرب، الطلاب، نسب التقدم، النتائج، الواجبات المنتظرة، الأسئلة، وإحصاءات موجزة.
- تمكين المدرب داخل دوراته المعيّنة من تعديل المحتوى والوحدات والدروس والوسائط، متابعة الطلاب، تقييم الواجبات، والرد على الأسئلة.
- منع المدرب من رؤية أو تعديل دورات أو طلاب خارج نطاق تكليفه.

## 6. إدارة الأكاديمية
- إضافة قسم كامل داخل الإدارة لعرض وإنشاء وتعديل وحذف الدورات الآمن، والنشر وإلغاء النشر والأرشفة.
- إدارة صورة الدورة، المدرب، التصنيف، المستوى، المدة، الوصف، المخرجات، المتطلبات، وقواعد الإكمال.
- إدارة الوحدات والدروس وترتيبها، الفيديوهات، الملفات، الاختبارات، الأسئلة، الإجابات الصحيحة، الواجبات والمشاريع.
- إدارة الطلاب والتسجيلات والتقدم والنتائج والتقييمات والشهادات.
- الحذف النهائي يتطلب تأكيدًا ويُمنع عندما توجد سجلات تعلم أو شهادات مرتبطة؛ عندها تُستخدم الأرشفة للحفاظ على السجلات.

## 7. الحالات والربط
- معالجة حالات: غير مسجل، مسجل ولم يبدأ، قيد التعلم، مكتمل، درس مقفل، اختبار غير مجتاز، واجب ينتظر التقييم، دورة غير منشورة، وشهادة غير موجودة.
- توفير حالات Loading وEmpty وError وOffline وإعادة المحاولة دون فقدان إدخال المستخدم.
- إكمال تسجيل الدخول والحساب بالقدر اللازم لكي تعمل التسجيلات والتقدم والشهادات ولوحات الصلاحيات فعليًا.
- إبقاء روابط الصفحة الرئيسية والتنقل الحالية، وربط جميع صفحات الأكاديمية الجديدة دون تغيير الأقسام غير المرتبطة.

## 8. التحقق النهائي
- اختبار رحلة الطالب كاملة: تسجيل الدخول، الالتحاق، متابعة درس، ملاحظة، اختبار، واجب، إكمال، شهادة، والتحقق عبر QR.
- اختبار رحلة المدرب والمسؤول وصلاحيات المنع بين الحسابات.
- اختبار رفع واستبدال صورة دورة والملفات، ومنع الأنواع أو الأحجام غير المقبولة.
- فحص الهاتف وسطح المكتب، الروابط، الحالات الفارغة والأخطاء، وسلامة البناء وعدم ظهور أخطاء في المتصفح.
- إضافة عناوين ووصف مشاركة فريد لكل صفحة جديدة.

## تفاصيل تقنية
- تُنفذ تغييرات البيانات في ترحيل جديد دون تعديل الترحيل السابق، مع GRANT ثم RLS ثم السياسات لكل جدول جديد.
- تُحدّث دوال التقدم والإكمال لتشمل الوحدات والاختبارات والواجبات المطلوبة وتعمل داخل معاملة واحدة مع قيود فريدة لمنع الشهادات المكررة.
- يُستخدم التخزين الخاص وروابط قصيرة العمر للوسائط، مع مسارات منفصلة للدورات والدروس والواجبات والتحقق من الملكية والصلاحية.
- تُستخدم مكتبة QR الموجودة حاليًا، ويُولّد الرمز من رابط التحقق العام الفعلي.
